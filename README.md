# Admin Solutions, LLC website

Live site: https://www.adminsolutionllc.com

Plain HTML site hosted free on GitHub Pages. Any change saved to the `main` branch goes live in about a minute.

- `index.html` – homepage (services, Business Advisory, about, reviews, contact)
- `business-insights.html` – Business Insights articles (new article added monthly)
- Images, `robots.txt`, `sitemap.xml`, and `CNAME` (the custom domain) sit alongside.
